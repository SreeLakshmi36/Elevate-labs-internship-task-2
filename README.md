# Elevate-labs-internship-task-2
Superstore Sales Data Visualization & Storytelling

Task Overview
This project focuses on visualizing sales data using Power BI to derive meaningful business insights. The Superstore dataset is analyzed to understand sales performance, profitability, and regional trends through interactive dashboards.

Tools Used:
Power BI Desktop,
Superstore Sales Dataset (CSV)

Project Pages:
Overview Dashboard,
Total Sales & Total Profit (KPIs),
Monthly Sales Trend,
Sales by Category,
Profit by Region,
Detailed Analysis,
Top Sub-Categories by Sales,
Sub-Categories by Profit,
Sales by State (Map)

Summary & Storytelling:
Key Business Insights,
Business Recommendations

Key Insights:
Technology is the highest selling category.
Phones and Chairs are top-selling sub-categories.

West and East regions generate the highest profit.

Some products show low or negative profit.

Deliverable

Superstore_Visualization(Final Visual Report)
